## 固定基准

造型唯一首要依据：../kiki-character-studies.png（用户确认）。
Logo 唯一原文件：../kiki-logo-clear-reference.png。不得用 AI 字体近似稿替代。
材质辅助参考：../08-coin-purse.png，仅用于表面短绒，禁止沿用零钱包比例。

## 本轮验收与接入

- standing、coffee、croissant：本轮草图转材质版本，接入项目的站姿主图、喝咖啡、吃可颂静态图。保留草图的大帽、窄白脸、碗形身体、细肢、椭圆鞋和两瓣嘴结构；仍是 AI 辅助概念渲染，不是尺寸精确的生产图。
- croissant 对齐草图下方中间的单脚动作，而不是上一版坐姿。
- bakery、packaging、gift、lifestyle：尝试稿。部分纹理仍残留，含字标区域无法保证像素级一致。仅放在修订预览，不覆盖正式页面。
- 前一轮三张展板未通过角色/字标一致性检查，不接入主页面，本轮不再沿用其错误角色作参考。
- 原图、视频、用户草图和原 Logo 全部保留。

生成模式：内置 image_gen。没有使用 CLI，也没有代码修改图片内容。仅 sips 转换网页 JPEG。
