# Nikki Fu Portfolio V2 Design System

## Direction

Chinese is the primary language. English works as labels, categories, proof points and supporting context.

The visual tone is editorial, commercial and precise: black, white, grey, and one bright accent.

## Typography

- UI / body font: Inter, Helvetica Neue, PingFang SC, system sans-serif.
- Display title: 72-120px on desktop, 46-64px on mobile.
- Section title: 44-88px on desktop, 36-46px on mobile.
- Case title: 34-72px depending on layout.
- Body: 16-18px.
- Caption / label: 12-13px uppercase English or short bilingual labels.

## Colors

- Ink: `#111111`
- Graphite: `#2B2B2B`
- Grey: `#6F6F6F`
- Soft grey: `#A6A6A6`
- Line: `#D8D8D8`
- Paper: `#F4F4F1`
- White: `#FFFFFF`
- Accent: `#D7FF3F`

Use the accent only for proof points, active states, section emphasis and selected metrics.

## Content Blocks

- Image block: use `.media-frame` for JPG, PNG, GIF and exported Figma screenshots.
- Video block: use `.media-frame` for MP4 / WebM. Keep muted, looped and plays inline unless the video needs sound.
- HTML block: use `.html-embed` for embedded webpage demonstrations, interactive fragments or exported HTML snippets.
- Data block: use `.data-strip` for conversion, orders, revenue, campaign count and time saved.

## Case Page Rhythm

1. Hero: one-line business context and project claim.
2. Snapshot: role, scope, timeline, tools, data permission.
3. Problem: what was broken or inefficient.
4. Strategy: why this direction.
5. Evidence: website / images / video / HTML embed.
6. Growth logic: how it affects traffic, conversion, AOV or repeat purchase.
7. Result: measurable data and what the project proves.
