# Portfolio image policy

- Use supplied original image files byte for byte. Do not compress, downsample, re-encode or generate smaller delivery variants unless Nikki explicitly requests it.
- Do not run the legacy WebP optimization script; it is disabled.
- Do not select lower-resolution srcset variants for project artwork. Preserve native PNG/JPEG/WebP originals and use vector exports from original PDFs for vector artwork.
- Never upscale a small raster to claim higher resolution. Keep original sources unchanged.
- Project covers and artwork selections require preserving the user-selected image.
